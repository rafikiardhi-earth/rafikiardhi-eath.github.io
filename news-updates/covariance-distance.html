Covariance Distance Explorer

Calculate Mahalanobis distance from a mean vector and covariance matrix. Explore how variance and correlation change multivariate distance, with transparent validation and no data sent anywhere.

Input data

Use the longer worked example, enter values manually, or open a CSV containing observations. CSV mode calculates a mean and sample covariance from selected numeric columns, then lets you choose a row to measure against that reference.

Rows and columns must follow the same variable order as x and μ.

<h2>What is being calculated?</h2>
<p>Mahalanobis distance measures how far a vector is from a reference mean while accounting for covariance among variables.</p>
<p><strong>Squared Mahalanobis distance: D² = (x − μ)ᵀ P (x − μ)</strong>, where P is the precision matrix (Σ⁻¹).</p>
<p><strong>Squared Euclidean distance: E² = Σᵢ(xᵢ − μᵢ)²</strong>; Euclidean distance is √E².</p>
<p class="muted">Euclidean distance treats each variable axis equally in the supplied units. Mahalanobis distance accounts for covariance and variable scales. Neither distance is a probability by itself.</p>
